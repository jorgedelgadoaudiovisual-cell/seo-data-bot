Cómo funciona

Un bot que nunca duerme

Infraestructura 100% automática y transparente: el mismo pipeline abierto que genera esta página.

Recolección diaria automática

Cada día a las 06:00 UTC un GitHub Action consulta la API pública de GitHub, detecta los repos nuevos con más tracción y genera un snapshot con fecha.

Datos abiertos y versionados

Cada snapshot se publica en JSON y CSV con su fecha. El histórico acumulado permite ver cómo evolucionan las tendencias semana a semana.

Señal para SEO y mercado

Detecta qué tecnologías despegan antes que nadie: insumo directo para contenidos, herramientas y decisiones de producto.
